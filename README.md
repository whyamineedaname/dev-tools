# dev-tools
兔丝 是一款开箱即用的 Windows 桌面工具箱，把散落在各处的小工具收进一个本地应用。文本处理（JSON、加解密、正则、时间戳、格式互转……）、文档转换（转 Markdown / PDF / 阅读器）、图片处理（取色、去背景、压缩、EXIF、拼图）、音视频（转码、人声分离）、网络调试（HTTP、端口、DNS）五大类 30 余个工具，双击即可使用。  所有处理都在本机完成，不上传任何文件，隐私安全；工具采用「按需环境」设计——大部分开箱即用，仅文档转换、音视频类工具按需配置 Python / FFmpeg，不需要也可以跳过。轻量、本地、即开即用，是日常办公与开发排障的顺手工具箱。
